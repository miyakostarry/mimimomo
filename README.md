#mimimomo

Mimimomo is a flower-shaped MIDI controller PCB designed using KiCad. The project combines capacitive touch pads, mechanical switches, slide potentiometers, a rotary encoder, and RGB LEDs to create a custom music controller.

## Components Used

| Component                      | Quantity | Purpose                                                               |
| ------------------------------ | -------: | --------------------------------------------------------------------- |
| Waveshare ESP32-S3-Zero        |        1 | Microcontroller for processing inputs and handling MIDI communication |
| Capacitive touch pads          |        6 | Touch-based controls                                                  |
| SK6812 MINI-E RGB LEDs         |        6 | Lighting and visual feedback                                          |
| Bourns slide potentiometers    |        2 | Adjustable controls for parameters such as volume or effects          |
| EC11 rotary encoder            |        1 | Rotary input for adjusting values                                     |
| Kailh Choc mechanical switches |        4 | Physical button inputs                                                |

## Tools Used

* KiCad — PCB layout and schematic design
* Git — Version control
* GitHub — Project hosting and version management

## Work Completed

* Designed a flower-shaped PCB layout in KiCad.
* Created a custom hexagonal copper footprint for the touch pads.
* Added and positioned the components on the PCB.
* Arranged the components to fit the flower-shaped design.
* Explored routing connections across the front and back copper layers.
* Planned the placement of RGB LEDs on the back of the PCB.
* Uploaded the KiCad project files and custom touch-pad footprint to GitHub.




## Repository Structure

* `mimi-kicad/` — KiCad project files, including the schematic and PCB layout.
* `touch_padd.pretty/` — Custom capacitive touch-pad footprint library.
